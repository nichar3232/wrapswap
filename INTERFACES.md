# WrapSwap workstream contract v1
Only root changes this document. Solidity 0.8.26/cancun. ERC20 amounts are RAW token units; shares and USD/share prices are 1e18. All JSON integers that may exceed JS safe range are decimal strings. Addresses are hex. Amount normalization is amount*spt/10**tokenDecimals (uAAPL uses 18); redemption is shares*10**decimals/spt. USDC is 6 decimals. FullMath and upward rounding for required input; downward rounding for output. No inventory withdrawal may impair vault backing. No mock PoolManager.

## Postgres schema
Use NUMERIC(78,0) for chain integers; TEXT for hashes/addresses; bool BOOLEAN. Add chain_id INTEGER, log_index INTEGER and event unique keys where multiple events occur per tx; block hash for reorg cleanup. SQL migrations own canonical schema.
conversions(tx TEXT,log_index INTEGER,chain_id INTEGER,block NUMERIC,ts NUMERIC,from_token TEXT,to_token TEXT,shares NUMERIC,fee_bps INTEGER,filled_by_hook BOOLEAN,trader TEXT,PRIMARY KEY(chain_id,tx,log_index)); batches(batch_id NUMERIC PRIMARY KEY,phase TEXT,mid NUMERIC,mid_source TEXT,crossed_qty NUMERIC,routed_qty NUMERIC,settled_tx TEXT); orders(batch_id NUMERIC,trader TEXT,commit_hash TEXT,revealed BOOLEAN,is_buy BOOLEAN,qty NUMERIC,limit_px NUMERIC,route_residual BOOLEAN,PRIMARY KEY(batch_id,trader)); fills(batch_id NUMERIC,trader TEXT,is_buy BOOLEAN,qty NUMERIC,px NUMERIC,kind TEXT CHECK(kind IN ('cross','lit')),tx TEXT,log_index INTEGER,PRIMARY KEY(tx,log_index)); backing_snapshots(block NUMERIC,issuer TEXT,tokens_held NUMERIC,spt NUMERIC,shares NUMERIC,supply NUMERIC,PRIMARY KEY(block,issuer)); hook_inventory(block NUMERIC,pool_id TEXT,currency TEXT,amount NUMERIC,fee_accrued NUMERIC,PRIMARY KEY(block,pool_id,currency)); intents(hash TEXT PRIMARY KEY,status TEXT,input_amount NUMERIC,min_out NUMERIC,filled_amount NUMERIC,filler TEXT,opened_tx TEXT,filled_tx TEXT,finalized_tx TEXT); cursor(chain_id INTEGER PRIMARY KEY,last_block NUMERIC).

## Exact make demo sequence
1. scripts/demo.sh verifies env/toolchain/Postgres, starts owned Anvil Base fork port 8545 with 2s blocks, waits eth_chainId; logs/fork.log. Refuse unknown occupied port.
2. make deploy-local → forge script contracts/script/Deploy.s.sol:Deploy --rpc-url localhost:8545 --broadcast; scripts/export-abis.sh generates ABIs and local manifest.
3. make seed → scripts/seed.ts funds deployer only on local fork, invokes Seed.s.sol, sets up claim inventory and PositionManager liquidity, three public burners and dark escrow, prepares oracle/TWAP history.
4. scripts/demo-flow.ts executes vault conversion, parity fill, inventory drain/fallthrough/restoration, three-wallet commit/reveal/settle with Crossed and RoutedToLit assertions; every receipt hash printed.
5. migrate DB; concurrently launch API :4000, crank :4001, web :5173; all logs in logs/; print http://localhost:5173 . DEMO_CHECK=1 executes finite health+Playwright checks and exits owned processes for fresh-clone-check.
6. fresh-clone-check clones HEAD into /tmp, installs dependencies, copies only ignored RPC config (never public deployer secret), generates fresh ignored local key, runs DEMO_CHECK=1 make demo on isolated ports or after orderly demo shutdown. Must test clean clone, never workspace fallbacks.

## Accepted contract additions
Registry active(address token)→bool combines registration and pause state. Vault pullInventory(address token,uint256 amount) only authorized provider, post-transfer backing invariant enforced. Calendar setEarlyClose(uint256 day,uint256 secondsAfterMidnight) owner, default regular close.
Dark getters: poolKey()→PoolKey; orders(batch,trader)→(bytes32 hash,Currency currency,uint256 locked,bool revealed,bool isBuy,uint256 qty,uint256 limitPx,bool routeResidual,uint256 crossed); participants(batch)→address[]; settled(batch)→bool; observationCount()/observationIndex(); twapPrice()→uint256; priceToSqrt(uint256)→uint160; requiredBuyLock(uint256 qty,uint256 price)→uint256. ResidualSkipped event reports an isolated failed residual without losing escrow. Configure pool after initialize and seed observation history before TWAP use. Production liquidity gating evaluates callback sender (PositionManager/router must be attested).

Indexer deployment provenance table: indexer_deployments(chain_id INTEGER PRIMARY KEY,identity TEXT NOT NULL). On identity change (manifest deploy block and core application addresses), transactionally clear only indexer-owned journal/projections/cursor before replay. Fresh clone uses a separate local Postgres database to avoid competing indexers.
Lit pool uses tickSpacing=1 and ±2% price boundaries rounded outward to ticks (less than 1bp rounding). Parity pools use tickSpacing=60. Seed reads actual spacing from manifest.
Demo orchestration amendment: concurrently starts API/crank/web immediately after seed so the scripted phase transition is settled by the running crank; final URL prints after scripted assertions. This resolves the original sequence's requirement for a running crank before its later startup step.
